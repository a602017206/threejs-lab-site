# Digi1 data sources

Catalog prose, names, stages, attributes, types, evolution links, and Adventure (1999) episode data were compiled from:

- [Digimon Reference Book](https://digimon.net/reference_en/) — official Digimon species reference.
- [Wikimon](https://wikimon.net/) — species pages and the [Digimon Adventure episode list](https://wikimon.net/List_of_Digimon_Adventure_episodes).

Individual records link to their relevant Wikimon and/or episode pages in `src/digi1/catalog.json`.

The artwork and thumbnails in this directory were obtained via digi-api; see `credits.json` for the recorded source of each image. The game models come from Digimon Story: Time Stranger via the DSTS Model Viewer. These images and game models have not been authorized by the rights holders and are presented for reference.
